МатНМТ API (0.2.0)

Download OpenAPI specification:

REST API платформи підготовки до НМТ з математики (Next.js Route Handlers + Prisma + PostgreSQL). Документацію складено за кодом у src/app/api станом на 06.11.2026. Паролі зберігаються як bcrypt-хеш і ніколи не повертаються у відповідях.

Вхід. Через Auth.js (/api/auth/*): POST /api/auth/callback/credentials з email і паролем встановлює підписану cookie сесії (authjs.session-token). Маршрути з позначкою sessionCookie працюють лише для користувача, що ввійшов, і лише з його власними даними.

Помилки мають вигляд { "error": "..." }: 400 — некоректні дані, JSON або формат id; 401 — потрібен вхід; 403 — чужі дані; 404 — запис не знайдено; 409 — дублікат або порушено зв’язок між записами; 500 — внутрішня помилка (деталі лише в лозі сервера); 503 — БД недоступна.

Відомі обмеження: маршрути керування контентом (теми, задачі) і плани за planID ще не мають перевірки ролей і доступні без входу.

Створити план навчання

План створюється для користувача з сесії (userID у тілі ігнорується). Правила: дата НМТ — щонайменше через 7 днів; годин на тиждень — від 1 до 80 (UT-12, UT-13).

sessionCookie
Request Body schema: application/json
required
hours
integer [ 1 .. 80 ]

string <date-time>

sessionCookie

required
taskID
required
string <uuid>
required
