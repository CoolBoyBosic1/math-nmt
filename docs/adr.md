# Архітектурні рішення (ADR) — МатНМТ

Статус: прийнято · 31.10.2026 · відповідальні: Микола Ладіков-Роєв, Олександр Тимченко

МатНМТ — моноліт на Next.js 15: інтерфейс і REST API в одному застосунку, дані в PostgreSQL через Prisma.
Головний критерій усіх рішень — команда з трьох людей має довести MVP до 27.12.2026, тому обираємо
один TypeScript-стек від інтерфейсу до бази, мінімум власної інфраструктури і безкоштовні сервіси.

## Архітектура

```
Браузер (React 18, Bootstrap)
   │  fetch /api/...
   ▼
Next.js 15 App Router
   ├─ src/app/**/page.tsx          сторінки (клієнтські компоненти)
   ├─ src/app/api/**/route.ts      Route Handlers — REST API, 33 операції
   └─ src/lib/                     валідатори, робота з паролями, клієнт БД
   │
   ▼  Prisma Client (Rust-free) + @prisma/adapter-pg
PostgreSQL 16 — 7 таблиць: User, Topic, Theory, Task, UserTask, Plan, PlanTask
```

Діаграми: `docs/uml/` (прецеденти, класи, послідовності, компоненти й розгортання, ER).
Контракт API: `docs/openapi.yaml`, переглядач — `docs/api-docs.html`.

Шари і правила залежностей:

1. **Сторінки** звертаються до даних лише через `/api/*` (відносні URL), ніколи напряму до БД.
2. **Route Handlers** перевіряють вхідні дані валідаторами з `src/lib/validator`, викликають Prisma і повертають JSON. Пароль ніколи не потрапляє у відповідь (`publicUserSelect`).
3. **`src/lib/db.ts`** — один екземпляр PrismaClient на процес.
4. **Схема БД** змінюється тільки міграціями (`prisma/migrations`), тестові дані — `prisma/seed.ts`.

## Наслідки

- Один застосунок і одна мова знижують навантаження на команду, але API і UI масштабуються разом. Якщо API знадобиться окремо (мобільний застосунок у 2027 році), Route Handlers переносяться в окремий сервіс без зміни контракту OpenAPI.
- Логіка плану поки рахується в браузері; у Sprint 6 її переносимо в сервіс на сервері, щоб покрити тестами і використовувати в рекомендаціях.
- Умови задач зберігаються як PNG — це обмежує пошук і ШІ-генерацію; пілот тексту з KaTeX запланований на Sprint 8.
- Будь-яке нове рішення такого рівня додається в цю таблицю з причиною й альтернативою.
